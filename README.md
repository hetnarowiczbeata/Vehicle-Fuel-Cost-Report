# Vehicle Fuel Cost Report

## Overview

This project retrieves historical fuel prices from the Orlen API, transforms the data, and stores it in an Excel file for further analysis and reporting.

The solution can be extended with a database (PostgreSQL) and Power BI dashboards for automated fuel cost monitoring and trend analysis.

## Features

Fetch historical fuel prices from the Orlen API
Convert fuel prices from m³ units to liters
-Transform API responses into a structured dataset
-Export data to Excel
-Support for multiple fuel products
